## Overview

A modern, responsive business website for Sama — a certified hair extension specialist based in the UK. The site showcases services, a photo gallery, client testimonials, and provides an easy way for clients to get in touch and book appointments.

---

## Pages

| Page | Description |
|------|-------------|
| Home | Hero section, stats, about Sama, why choose us, testimonials, booking CTA |
| Services | Full list of extension methods with descriptions and pricing |
| Gallery | Photo gallery of client transformations |
| Contact | Contact form and booking information |

---

## Features

- Fully responsive, mobile-first design
- SEO-optimised with react-helmet-async (per-page meta tags)
- Smooth scroll-to-top on route changes
- Clean CSS with modular per-page stylesheets
- Client testimonials section
- Stats display (experience, clients, rating)

## Getting Started

```bash
git clone https://github.com/ImanSalehinia/SamaHairExtensions.git
cd SamaHairExtensions
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
